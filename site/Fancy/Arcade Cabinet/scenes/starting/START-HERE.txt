ARCADE CABINET — STARTING SOON SCENE (STREAMELEMENTS)

This is the "Starting soon" scene of Arcade Cabinet. Give it its own StreamElements overlay and its own OBS scene.

INSTALL
1. In StreamElements create a new 1920 x 1080 overlay for this scene.
2. Add a Static/Custom > Custom Widget. Set it to 1920 x 1080 at X=0, Y=0.
3. Open the widget's code editor. Replace the HTML, CSS, JS and FIELDS tabs with the four
   boxes from the overlay site ("Copy to StreamElements"). Save.
4. In OBS make a "Starting soon" scene and add the overlay URL as a Browser Source, 1920 x 1080,
   placed ABOVE your other sources.
5. Test with StreamElements "Emulate" (follow, sub, tip, cheer, raid) and a real chat message.

SCENE TRANSITION
This scene plays a short transition in its overlay's style when it appears.
In OBS: open this Browser Source's properties and tick "Refresh browser when scene
becomes active". For the smoothest switch, set the OBS scene transition to "Fade"
at about 300 ms. Turn it off with "Show scene transition" in the Fields panel.
